1. Melakukan eksport data dari dua grup WhatsApp

Menggunakan fitur "Export Chat" dari WhatsApp, hasilnya disimpan dalam file teks (.txt).

2. Membersihkan dan menggabungkan data

Baca file teks menggunakan Python, lakukan pembersihan data (hapus metadata seperti tanggal, waktu, dan nama pengirim menggunakan regex). Gabungkan data bersih menjadi file CSV bernama data_group.csv.


import re
import pandas as pd

def clean_data(file):
    with open(file, 'r', encoding='utf-8') as f:
        lines = f.readlines()
    cleaned_data = []
    for line in lines:
        match = re.search(r'^\[\d{2}/\d{2}/\d{4}, \d{2}:\d{2}\] .*?: (.+)', line)
        if match:
            cleaned_data.append(match.group(1))
    return cleaned_data

# Proses gabungan
group1 = clean_data('group1.txt')
group2 = clean_data('group2.txt')
all_data = group1 + group2
df = pd.DataFrame(all_data, columns=['Message'])
df.to_csv('data_group.csv', index=False)

4. Melakukan clustering dengan algoritma K-Means

Proses clustering dilakukan dengan mengubah teks menjadi fitur numerik menggunakan CountVectorizer, lalu menerapkan algoritma K-Means dengan berbagai nilai k.


from sklearn.feature_extraction.text import CountVectorizer
from sklearn.cluster import KMeans

# Vektorisasi teks
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(df['Message'])

# Clustering
kmeans = KMeans(n_clusters=3, random_state=42)
kmeans.fit(X)

# Hasil clustering
df['Cluster'] = kmeans.labels_
df.to_csv('clustered_data.csv', index=False)

5. Implementasi Metaflow

Untuk menjalankan algoritma K-Means dalam bentuk workflow, digunakan Metaflow. Workflow ini memungkinkan eksperimen dengan berbagai nilai k (jumlah cluster) dan mengelola hasil clustering dengan lebih terstruktur. Berikut adalah rangkaian langkah yang dilakukan dalam Metaflow:

  • Langkah pertama memuat data dan membuat matriks fitur dari data WhatsApp.
  • Setiap nilai k (3, 4, 5) diuji dengan melatih model K-Means dan menghasilkan label cluster.
  • Setelah itu, dilakukan analisis terhadap hasil clustering dengan menemukan kata-kata teratas per cluster.
  • Hasil analisis disusun dan disimpan dalam file output yang kemudian ditampilkan pada layar.

from metaflow import FlowSpec, step, Parameter, resources
from collections import Counter
import numpy as np

class ManyKmeansFlow(FlowSpec):

    num_docs = Parameter('num-docs', help='Number of documents', default=1000)

    @resources(memory=4000)
    @step
    def start(self):
        import scale_data
        docs = scale_data.load_yelp_reviews(self.num_docs)
        self.mtx, self.cols = scale_data.make_matrix(docs)
        self.k_params = list(range(3, 6, 1))
        self.next(self.train_kmeans, foreach='k_params')

    @step
    def train_kmeans(self):
        from sklearn.cluster import KMeans
        self.k = self.input
        kmeans_model = KMeans(n_clusters=self.k)
        kmeans_model.fit(self.mtx)
        self.kmeans_output = kmeans_model.labels_
        self.next(self.analyze)

    @step
    def analyze(self):
        clusters = self.kmeans_output
        cluster_docs = {i: [] for i in range(self.k)}
        for doc_idx, cluster_id in enumerate(clusters):
            cluster_docs[cluster_id].append(doc_idx)

        top_words_per_cluster = {}
        for cluster_id, doc_indices in cluster_docs.items():
            word_counts = Counter()
            for doc_idx in doc_indices:
                word_counts.update(self.mtx[doc_idx].nonzero()[1])

            words_with_freq = [(self.cols[word_idx], count) for word_idx, count in word_counts.most_common(3)]
            top_words_per_cluster[cluster_id] = words_with_freq

        self.top_words = top_words_per_cluster
        self.next(self.join)

    @step
    def join(self, inputs):
        self.top = {inp.k: inp.top_words for inp in inputs}
        self.next(self.end)

    @step
    def end(self):
        with open('output.txt', 'w') as f:
            for k, clusters in self.top.items():
                f.write(f"For k={k}:\n")
                for cluster_id, words in clusters.items():
                    f.write(f" Cluster {cluster_id}: {words}\n")

        print("Top words for each k:")
        for k, clusters in self.top.items():
            print(f"For k={k}:")
            for cluster_id, words in clusters.items():
                print(f" Cluster {cluster_id}: {words}")
        print("Analysis: Clustering results indicate that...")
