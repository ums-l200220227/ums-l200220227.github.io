TUGAS sebelum UAS INFRASTRUKTUR dan PLATFORM SAINS DATA

Deskripsi

  • Melakukan eksplorasi dan analisis data dari dua grup WhatsApp yang berbeda.
  • Menggunakan algoritma K-Means untuk melakukan clustering pada data yang telah dibersihkan.

Cara Pengerjaan

Langkah-langkah:

  1. Eksport Data dari Grup WhatsApp:
    • Ekspor data percakapan dari dua grup WhatsApp dalam format file teks (.txt).
    • Pastikan data teks disimpan dengan encoding yang mendukung karakter khusus (contoh: UTF-8).
  2. Pembersihan dan Penggabungan Data:
    • Baca kedua file teks menggunakan Python.
    • Ekstrak pesan teks dari data dengan memisahkan metadata seperti tanggal, waktu, dan nama pengirim.
    • Hapus pesan sistem dan data lain yang tidak relevan.
    • Gabungkan data bersih ke dalam satu file CSV bernama data_group.csv.
  3. Kompresi Data:
    • Kompresi file data_group.csv ke dalam format tar.gz menggunakan pustaka tarfile.
  4. Clustering dengan K-Means:
    • Gunakan algoritma K-Means untuk melakukan clustering pada data teks.
    • Hitung matriks data dengan CountVectorizer untuk memproses teks menjadi fitur numerik.
    • Lakukan iterasi dengan berbagai nilai k untuk menentukan jumlah cluster optimal.
  5. Analisis Hasil:
    • Identifikasi kata-kata kunci (top words) pada setiap cluster.
    • Buat laporan hasil clustering, termasuk pola yang ditemukan dalam data.

Implementasi Program

  1. Eksport dan Pembersihan Data:
    • Menggunakan Python untuk membaca file teks dan membersihkan data dengan regex.
    • Proses ini menghasilkan file data_group.csv yang hanya berisi pesan teks bersih.
  2. Kompresi Data:
    • File data_group.csv dikompresi menjadi data_group.tgz.
  3. Clustering dengan K-Means:
    • Proses clustering dilakukan dengan memanfaatkan sklearn.cluster.KMeans.
    • Pipeline clustering dibangun menggunakan Metaflow untuk mengotomatisasi eksperimen dengan berbagai nilai k.
  4. Analisis Hasil:
    • Hasil clustering dianalisis untuk menentukan pola dalam data, seperti kata-kata kunci pada tiap cluster.

Kesimpulan

  • Data dari dua grup WhatsApp berhasil diekspor, dibersihkan, dan digabungkan menjadi satu file CSV.
  • Data yang bersih dikompresi ke dalam format tar.gz untuk pengelolaan yang lebih efisien.
  • Algoritma K-Means berhasil digunakan untuk melakukan clustering pada data teks, dan hasil clustering menunjukkan pola yang berguna.
  • Pipeline Metaflow mempermudah eksperimen dengan berbagai nilai k.
