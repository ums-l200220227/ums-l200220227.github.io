TUGAS sebelum UAS INFRASTRUKTUR dan PLATFORM SAINS DATA

Deskripsi

  • Melakukan eksplorasi dan analisis data dari dua grup WhatsApp menggunakan algoritma K-Means.

Cara Pengerjaan

1. Melakukan eksport data dari dua grup WhatsApp

Menggunakan fitur "Export Chat" dari WhatsApp, hasilnya disimpan dalam file teks (.txt).

2. Membersihkan dan menggabungkan data

Baca file teks menggunakan Python, lakukan pembersihan data (hapus metadata seperti tanggal, waktu, dan nama pengirim menggunakan regex). Gabungkan data bersih menjadi file CSV bernama data_group.csv.


import re
import pandas as pd

def clean_data(file):
    with open(file, 'r', encoding='utf-8') as f:
        lines = f.readlines()
    cleaned_data = []
    for line in lines:
        match = re.search(r'^\[\d{2}/\d{2}/\d{4}, \d{2}:\d{2}\] .*?: (.+)', line)
        if match:
            cleaned_data.append(match.group(1))
    return cleaned_data

# Proses gabungan
group1 = clean_data('group1.txt')
group2 = clean_data('group2.txt')
all_data = group1 + group2
df = pd.DataFrame(all_data, columns=['Message'])
df.to_csv('data_group.csv', index=False)

3. Mengompresi file CSV

File data_group.csv dikompresi menjadi data_group.tar.gz menggunakan pustaka tarfile.


import tarfile

tar_file = 'data_group.tar.gz'
with tarfile.open(tar_file, 'w:gz') as tar:
    tar.add('data_group.csv')

4. Melakukan clustering dengan algoritma K-Means

Proses clustering dilakukan dengan mengubah teks menjadi fitur numerik menggunakan CountVectorizer, lalu menerapkan algoritma K-Means dengan berbagai nilai k.


from sklearn.feature_extraction.text import CountVectorizer
from sklearn.cluster import KMeans

# Vektorisasi teks
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(df['Message'])

# Clustering
kmeans = KMeans(n_clusters=3, random_state=42)
kmeans.fit(X)

# Hasil clustering
df['Cluster'] = kmeans.labels_
df.to_csv('clustered_data.csv', index=False)
